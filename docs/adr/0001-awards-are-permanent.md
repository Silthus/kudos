# Awards are permanent

Once a kudos message gives kudos, its awards never change: editing the message does not add, remove or move kudos, and deleting it does not take them back or refund the giver's daily allowance. The giver is told when an edit changes the mentions or the kudos emoji, and that a new message is the way to give more. We chose this over reversing awards on edit or deletion because progression, achievements and the leaderboard can then build on a record of awards that only ever grows, with no reversal path through XP, levels and unlocks, and because a recipient's recognition should not vanish when a message is tidied up. A wrong award has no undo for now; an admin reversal belongs to operating Kudos, later.
