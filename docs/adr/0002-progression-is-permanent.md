# Progression is permanent

What a member earns through progression never goes away: XP and levels never reset or go down, a skill point once spent stays spent, unlocked cosmetics and kudos emoji stay unlocked, and coins earned stay earned until the member spends them. There is no respec in this map, and a perk that is retired or rebalanced stays with the members who bought it; balancing only changes what happens from then on. We chose this over seasons or decay, a respec, and taking retired perks back, because awards are already permanent ([ADR-0001](0001-awards-are-permanent.md)), so what they earned can be too, and because a choice only feels like a choice when it sticks. A coin-priced respec token is parked as a later store item.
