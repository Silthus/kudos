# Website

The browser package, the signed-in surface where a member sees their kudos beside App Home: a React shell in the PostHog brand, light and dark, with the HedgeHug logo beside the wordmark in its header, above the name on the closed page and as its favicon, and a sign-in page that stands alone without the header: a narrow card with the hand-clasp hedgehog above the name, a full-width primary action to Slack and, while a deep link to a listed path waits, the path the member lands on afterwards, built by Vite and served from the deployment's own `*.convex.site` root by the static hosting component, after Slack's routes, with a strict Content Security Policy header on every HTML response. The shell holds no member data: it signs in with Slack through Convex Auth's React client and returns to the page the sign-in started from, keeping the one-time code in the query string until Convex Auth redeems it, and renders one page from the one answer getMyProfile gives (closed, signed-out, verifying, unverified, not-a-member or member). Before the answer names a member, each page carries one hedgehog and one sentence from Max under the visitors' header, which holds the wordmark, the `Feedback` control while the visit is captured and the theme control, and an unknown path shows the not-found page; every member gets the album, the website's only shell, from the one getAlbum answer, as the album bullets below say, and every URL Slack has sent lands on an album page. It shows "Sign-in didn't finish" when a sign-in this browser started comes back signed out or Convex Auth's redemption of the one-time code Slack's return brings is rejected, which Convex Auth drops unhandled and would otherwise leave loading forever, shows "Can't reach HedgeHug" when the socket to the deployment stays unconnected for five seconds while the answer is still loading, sets the theme from a blocking script in the page's head before the first paint, and moves focus to the page title when the answer changes; a fixture build renders the same pages from typed fixtures. While getAlbum answers a last visit, the album shell sends arrive once a visit with the last visit it read and, once that answers, labels `New` each held person's sticker on its team pages and person page, each team sticker and each hoggie plate put in after that last visit, for the rest of the visit (LP22).
