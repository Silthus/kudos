# Website

The browser package, the signed-in surface where a member sees their kudos beside App Home: a React shell in the PostHog brand, light and dark, built by Vite and served from the deployment's own `*.convex.site` root by the static hosting component, after Slack's routes, with a strict Content Security Policy header on every HTML response. The shell holds no member data: it signs in with Slack through Convex Auth's React client, renders one page from the one answer getMyProfile gives (closed, signed-out, verifying, unverified, not-a-member or member), where a member's home leads with thanking someone in Slack, then the kudos left and the refill time, and, while the answer carries a progression, one quiet line with the level, the XP to the next level and a neutral bar, then Max's line on this week, the counters, the profile card that keeps received kudos private and shows the level when there is one, a neutral level ring on the member's face in the hero and the avatar menu while there is a level, and the later features: while the answer carries no unlock path, as plain locked cards, with the leaderboard as a plain card linking to its page while the answer says it is open; while it carries one, only the shipped features it lists, in three groups in its order, "Ready for you" as closed crates labelled with what each unlocks and an outline "Open", "Open" linking to the feature's page or pointing there with an action to Slack, and "Still locked" with "Unlocks at level {level}" and no progress. While the answer carries Journey steps, a Journey panel sits between the counters and those groups, listing each active step's goal, hint and XP, a finished step as its reward crate pointing to Slack's App Home, and an opened one as done, with no step count. The path picks the page: the home at `/`, the leaderboard at `/leaderboard` with its period in the query string, the quests at `/quests`, and the not-found page everywhere else. The screen nav links `/` and each open feature that has a page, and its page renders the one answer getLeaderboard gives for the period: the board card with the member's standing, a headline naming the lead, a neutral podium where a tie stands level, the rest of the window with a gap line, the whole board centred on the member with their row pinned and "Jump to me" while it is scrolled away, the private improvement line and how it counts, or one hedgehog and an action to Slack when nobody is ranked; while the answer is locked, Max says that sentence instead, with a link home, and while it is ready, the page shows the crate with a primary "Open" in its place. The quests page renders the one answer getQuests gives the same way: this week's quest cards with their kind, goal, a neutral progressbar, the XP and a "Swapped" tag, a finished quest as its reward crate pointing to Slack's App Home and an opened one as done, the crates of earlier weeks waiting to open, one hedgehog and an action to Slack when nothing was drawn, and how quests work, with no swap, group or bonus quest. A crate's "Open", and the HUD's ready pill, which counts the ready crates and takes the first, send openFeature and say "Opening…" until it answers: only "opened" plays the full-screen reveal, once per member and crate in this browser by the read's opaque seen key, skipped by a click or a key, shown at once under reduced motion, with a button to play it again and one to close it, and focus back on the feature's card or the page title; a refusal or an unreachable server is said in a live region, which also says what opened. It shows "Sign-in didn't finish" when a sign-in this browser started comes back signed out or Convex Auth's redemption of the one-time code Slack's return brings is rejected, which Convex Auth drops unhandled and would otherwise leave loading forever, shows "Can't reach HedgeHug" when the socket to the deployment stays unconnected for five seconds while the answer is still loading, sets the theme from a blocking script in the page's head before the first paint, signs out from the avatar menu, and moves focus to the page title when the answer changes; a fixture build renders the same pages from typed fixtures.

## entrances
- route GET /*: a browser asks for a page or a built asset of the website; a path without a file falls back to the shell
  handler: registerWebsite in convex/website/hosting.ts
  trust: browser
  control: none — it serves public static bytes built from this repository, which hold no member data and no secret; every HTML response carries the Content Security Policy header that forbids framing and foreign scripts (WS25)
