# #110 running-app proof

A disposable local Convex backend (`i110`, ports 3710/3711, storage under `/tmp`), never a cloud deployment.

- **Flag override:** `website` is on only for this backend. Its `POSTHOG_HOST` points at the mock Slack issuer (`testing/handshake/serveMockSlack.ts`, `MOCK_SLACK_PORT=3712`), which serves the flag on. Nothing reaches PostHog.
- **Sign-in:** a real Convex Auth handshake in the T3 preview browser against the mock issuer, signing in the synthetic member `U_ADA` under the invented name "Wren Halloway" (`POST /control/next`), with no Slack picture.
- **The live adapter:** `companyProfiles/sync:syncCompanyProfiles` ran once against posthog.com's public team API from this backend. The first run logged `companyProfiles.read_failed { reason: 'malformed' }`: some live teams carry no slug. That became the test "a profile on a team without a slug is still a face" (`red-team-without-slug.txt`). After the fix the run stored rows, and a script checked them without printing any: rows present, every cutout sized on `res.cloudinary.com` (`c_limit,w_160,f_auto,q_auto`), every colour a hex, every name normalised. One sized cutout answered `200 image/png`. The rows were then replaced with synthetic ones, and no live row, name or count is in this repo.
- **Company-profile face:** the table holds one synthetic profile, "Wren Halloway", with Cloudinary's public demo cutout `demo/.../docs/rmv_bgd/stuffed.png` on `#8567FF`. `company-face-light.png` and `company-face-dark.png`: the hero, the profile card and the avatar show the cutout on its colour, set through React's style property under the shell's CSP. The browser read `rgb(133, 103, 255)` behind all three.
- **Fallback:** while the page stayed open, the table was replaced with an unrelated invented profile and two "Wren Halloway" namesakes, only one of them with a cutout (the review's finding 2). The page turned to the initials tile with no reload (`fallback-initials-dark.png`, `fallback-initials-light.png`), since two people share the name and the mock gives no Slack picture.
- The console's one `style-src` error fires on the signed-out page before any face renders, so it predates this ticket.
